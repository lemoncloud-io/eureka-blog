## 1. AEO

### 1.1 정의

AEO는 **Answer Engine Optimization**의 약자이며, **답변엔진 최적화**를 의미한다.

AEO는 ChatGPT, Gemini, Google AI Overviews와 같은 AI 기반 답변 시스템이 콘텐츠를 이해하고, 답변 생성 과정에서 참고하거나 인용할 수 있도록 콘텐츠를 구조화하는 최적화 방식이다.

### 1.2 목적

AEO의 목적은 사용자가 AI에게  질문했을 때, 특정 콘텐츠가 답변의 근거로 활용되거나 출처로 연결될 가능성을 높이는 것이다.

---

## 2. AEO 필요성

### 2.1 검색 방식의 변화

기존 검색은 사용자가 검색어를 입력하고, 검색 결과 목록에서 여러 웹페이지를 직접 비교하는 방식이다.

AI 기반 검색은 사용자의 질문에 대해 요약된 답변을 먼저 제공하고, 필요한 경우 관련 출처나 링크를 함께 제공하는 방식이다.

### 2.2 콘텐츠 노출 방식의 변화

AI 답변 환경에서는 사용자가 웹페이지를 직접 클릭하기 전에 AI가 먼저 정보를 정리해 보여줄 수 있다.

따라서 콘텐츠는 검색 결과에 노출되는 것뿐 아니라, AI가 이해하고 답변에 활용하기 쉬운 형태로 작성하는 것이 AEO의 핵심 방향이다.

### 2.3 공개 콘텐츠의 영향

AI 답변 시스템은 접근 가능한 공개 콘텐츠를 참고해 답변을 구성할 수 있다.

AEO는 특정 채널에만 적용되는 방식이 아니라, AI가 접근하고 해석할 수 있는 공개 콘텐츠 전반에 적용되는 최적화 방식이다.

## 3. SEO와 AEO의 차이

| 구분     | SEO                        | AEO                                |
| ------ | -------------------------- | ---------------------------------- |
| 전체 명칭  | Search Engine Optimization | Answer Engine Optimization         |
| 한국어 의미 | 검색엔진 최적화                   | 답변엔진 최적화                           |
| 주요 대상  | Google, Naver 등 검색엔진       | ChatGPT, Gemini 등 AI 답변 시스템        |
| 목표     | 검색 결과 상위 노출                | AI 답변 내 참고 또는 인용 가능성 향상            |
| 주요 흐름  | 검색 → 검색 결과 클릭 → 웹사이트 방문    | 질문 → AI 답변 확인 → 필요 시 출처 방문         |
| 핵심 기준  | 키워드, 검색 의도, 페이지 품질, 링크     | 명확한 답변, 구조화된 정보, 신뢰 가능한 내용         |
| 성과 지표  | 검색 순위, 노출수, 클릭률, 방문자 수     | AI 답변 내 언급 여부, 출처 링크 여부, AI 유입 트래픽 |

## 4. Funnel 전략에서 AEO의 역할

### 4.1 적용 단계

AEO는 [Funnel 전략](https://github.com/lemoncloud-io/eureka-blog/blob/docs/blog/resources/references/funnel.md) 중 **TOFU(Top of Funnel: 인지)** 단계에 활용될 수 있다.

### 4.2 대상

AEO의 주요 대상은 문제 해결 또는 정보 검색을 위해 AI에게 질문하는 잠재 고객이다.

이 사용자는 아직 서비스를 인지하지 못했거나, 특정 문제에 대한 해결 방법을 찾는 단계에 있다.

### 4.3 역할

AEO는 잠재 고객이 AI에게 질문했을 때, 브랜드 또는 서비스 관련 콘텐츠가 AI 답변에 포함될 가능성을 높이는 데 사용된다.

이를 통해 사용자는 AI 답변 안에서 브랜드, 서비스, 관련 콘텐츠를 접할 수 있다.

### 4.4 Funnel 흐름

```md
사용자 질문
→ AI 답변 확인
→ 답변 내 브랜드, 서비스, 콘텐츠 인지
→ 블로그 또는 공식 페이지, 소셜 콘텐츠 방문
→ MOFU 단계로 이동
```

## 5. AEO 콘텐츠 작성 기준

### 5.1 질문 중심 구조

AEO 콘텐츠는 사용자가 실제로 질문할 가능성이 높은 문장을 기준으로 구성한다.

예시:

```md
- AEO란 무엇인가?
- SEO와 AEO는 무엇이 다른가?
- AI 답변에 인용되려면 콘텐츠를 어떻게 작성해야 하는가?
```

### 5.2 핵심 답변 우선 제시

각 섹션은 질문에 대한 직접적인 답변을 먼저 제시한다.

예시:

```md
## AEO란 무엇인가?

AEO는 Answer Engine Optimization의 약자로, AI 답변 시스템이 콘텐츠를 이해하고 답변에 활용할 수 있도록 콘텐츠를 최적화하는 방식이다.
```

핵심 정의가 앞에 있으면 사람과 AI 모두 문서의 주제를 빠르게 파악할 수 있다.

### 5.3 명확한 구조 사용

콘텐츠는 제목, 소제목, 문단, 목록을 통해 구조적으로 정리한다.

문서형 콘텐츠는 제목과 소제목을 명확하게 구분한다.

```md
# 문서 제목
## 대주제
### 세부 주제
```

짧은 콘텐츠는 첫 문장에 핵심 주제를 명확하게 배치한다.

### 5.4 구조화된 정보 사용

AEO 콘텐츠는 긴 문단보다 목록, 표, FAQ처럼 구조화된 형식이 적합하다.

활용 가능한 형식:

```md
- 정의
- 목적
- 대상
- 문제 상황
- 해결 방식
- 차이점
- FAQ
```

### 5.5 사실 기반 작성

AI 답변에 활용될 가능성을 높이기 위해 다음 요소를 콘텐츠 작성 기준으로 사용할 수 있다.

필요 요소:

```md
- 정확한 정의
- 일관된 용어 사용
- 과장 없는 표현
- 근거가 있는 설명
- 서비스와 직접 관련된 사실 정보
```

## 6. AEO 적용 방식

### 6.1 핵심 정의 정리

문서 초반에는 해당 주제의 정의와 핵심 요약을 배치한다.

예시:

```md
AEO는 AI 답변 시스템이 콘텐츠를 이해하고 답변에 활용할 수 있도록 콘텐츠를 구조화하는 최적화 방식이다.
```

### 6.2 FAQ 형식 활용

질문과 답변이 명확하게 분리된 FAQ 형식은 AEO에 적합하다.

예시:

```md
## FAQ

### AEO란 무엇인가?
AEO는 AI 답변 시스템이 콘텐츠를 이해하고 답변에 활용할 수 있도록 콘텐츠를 최적화하는 방식이다.

### AEO는 SEO와 다른가?
SEO는 검색 결과 상위 노출을 목표로 하고, AEO는 AI 답변 내 참고 또는 인용 가능성을 높이는 것을 목표로 한다.
```

### 6.3 비교 정보 제공

비교가 필요한 주제는 표로 정리한다.

예시:
```md
| 구분  | SEO         | AEO                     |
| --- | ----------- | ----------------------- |
| 목표  | 검색 결과 상위 노출 | AI 답변 내 참고 또는 인용 가능성 향상 |
| 대상  | 검색엔진        | AI 답변 시스템               |
```

### 6.4 공개 콘텐츠 간 연결

하나의 콘텐츠에서 모든 내용을 설명하지 않아도 된다.

각 콘텐츠는 같은 기준 정보를 바탕으로 작성되어야 하며, 필요하면 더 자세한 설명이 있는 콘텐츠로 연결한다.

## 7. 핵심 요약

AEO는 AI 답변 시스템에 콘텐츠가 참고되거나 인용될 가능성을 높이기 위한 답변엔진 최적화 방식이다.

Funnel 전략에서는 TOFU 단계에서 잠재 고객이 AI에게 질문했을 때 브랜드나 콘텐츠가 발견될 수 있도록 만드는 역할을 한다.

SEO는 검색 결과에서 발견되기 위한 최적화이고, AEO는 AI 답변에서 참고되기 위한 최적화이다.

```md
SEO = 검색 결과에서 발견되기 위한 최적화
AEO = AI 답변에서 참고되거나 인용되기 위한 최적화
```

AEO 콘텐츠는 질문 중심 구조, 명확한 답변, 구조화된 정보, 일관된 브랜드 설명, 사실 기반 내용으로 구성되어야 한다.
