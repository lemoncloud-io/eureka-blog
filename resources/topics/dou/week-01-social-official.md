# DoU Service

## 1. 서비스 개요

**DoU - 퍼스널 메신저**는 개인정보 보호에 초점을 둔 초대 기반 메신저 앱입니다.

기존 메신저처럼 연락처를 기반으로 자동 연결되는 방식이 아니라, 사용자가 직접 초대한 사람들과만 대화할 수 있습니다.  
불필요한 관계 연결 없이, 필요한 사람들과 안전하게 소통할 수 있는 **퍼스널 프라이버시 메신저**입니다.

> **한 줄 소개**  
> DoU는 나만의 클라우드에서 내가 초대한 사람들과만 안전하게 대화할 수 있는 초대 기반 퍼스널 메신저입니다.

---

## 2. 핵심 컨셉

DoU의 핵심은 **“내 대화는 내가 선택한 사람들과만”**입니다.

사용자는 자신만의 클라우드 공간을 생성하고, 그 안에 플레이스와 채팅방을 만들 수 있습니다.  
채팅방에는 초대한 사람만 참여할 수 있으며, 대화 내용은 나와 초대된 사람들만 확인할 수 있습니다.

DoU는 사용자 데이터를 제3자 회사나 기관과 공유하지 않으며, 데이터는 보안 연결을 통해 전송됩니다.
채팅방을 삭제하면 서버에 저장된 데이터도 삭제됩니다.

---

## 3. 서비스 구조

DoU는 아래 흐름으로 사용됩니다.

\`\`\`text
나만의 클라우드 생성
        ↓
플레이스 생성
        ↓
채팅방 운영
        ↓
원하는 사람 초대
        ↓
초대된 사람들과 프라이빗 대화
\`\`\`

즉, DoU는 사용자가 먼저 개인 클라우드 공간을 만들고, 그 안에서 필요한 사람들과만 대화하는 구조입니다.

---

## 4. 주요 기능

### 4-1. 플레이스

플레이스는 DoU에서 대화를 관리하는 공간입니다.  
사용자는 최대 5개의 플레이스를 생성할 수 있으며, 각 플레이스 안에서 채팅방을 운영할 수 있습니다.

플레이스에는 대화하고 싶은 사람만 초대할 수 있고, 초대를 수락한 사용자들끼리만 대화할 수 있습니다.

### 4-3. 나만의 클라우드

DoU에서는 사용자가 자신만의 클라우드 공간을 생성할 수 있습니다.

채팅방 안의 메시지는 사용자의 전용 클라우드에 존재하며, 앱 소유자인 회사는 해당 메시지를 확인하거나 활용할 수 없습니다.


### 4-4. 집중된 그룹 채팅

DoU의 채팅방은 최대 100명 규모로 운영됩니다.

대규모 공개방보다 필요한 사람들끼리 집중도 있게 대화하는 데 적합합니다.  
가족, 친구, 스터디, 프로젝트팀, 소규모 모임 등 비공개 그룹 커뮤니케이션에 활용할 수 있습니다.

## 6. DoU의 차별점

DoU의 가장 큰 차별점은 **관계와 데이터의 통제권을 사용자에게 준다**는 점입니다.

일반적인 메신저는 다양한 관계와 일상적으로 소통하는 범용 메신저라면, DoU는 **꼭 필요한 사람들과만 조용하고 안전하게 대화하기 위한 퍼스널 메신저**입니다.

DoU에서는 사용자가 직접 초대한 사람만 대화에 참여할 수 있습니다. 대화 공간은 나만의 클라우드 안에서 관리되며, 회사나 제3자가 채팅 내용을 확인하거나 활용할 수 없습니다. 또한 채팅방을 삭제하면 서버 데이터도 함께 삭제되어, 불필요한 대화 기록이 남지 않습니다.

즉, DoU는 더 많은 사람과 연결되기 위한 메신저가 아니라, **내가 선택한 사람들과 내가 관리하는 공간에서 대화하기 위한 프라이빗 대화 공간**입니다.

| 비교 항목  | 일반 메신저    | DoU          |
| ------ | --------- | ------------ |
| 성격     | 범용 메신저    | 퍼스널 메신저      |
| 연결     | 다양한 연결    | 초대 기반        |
| 관계     | 넓은 관계     | 선택한 관계       |
| 공간     | 서비스 중심    | 나만의 클라우드     |
| 데이터 접근 | 정책 기반     | 회사·제3자 접근 불가 |
| 삭제     | 기록 잔존 가능성 | 서버 데이터 삭제    |
| 상황     | 일상 소통     | 프라이빗 대화      |

## 7. 주요 타겟

DoU의 주요 타겟은 **프라이버시와 관계 분리를 중요하게 생각하는 20~30대 사용자**입니다.  

기존 메신저 안에서 모든 관계가 함께 존재하는 것보다, 필요한 사람들과만 분리된 공간에서 대화하고 싶은 사용자를 중심으로 합니다.

### 1차: 새로 운영할 목적형 대화가 있는 사용자

스터디, 사이드 프로젝트, 팀플, 공모전, 소규모 모임처럼 앞으로 함께 이어갈 대화가 있는 사용자입니다.

| 핵심 상황 | 새로 시작하거나 별도로 운영할 목적형 대화가 있음                           |
| ----- | ----------------------------------------------------- |
| 핵심 문제 | 기존 메신저에 채팅방을 하나 더 만들어도 같은 목록과 알림 흐름 안에서 다른 대화와 함께 존재함 |
| 행동 유도 | 해당 대화 주제를 DoU 플레이스로 만들고, 필요한 사람을 채팅방에 초대하게 한다         |

#### 예상 질문

| 질문                             | 대응                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| 기존 메신저에 채팅방 하나 더 만들면 되는 것 아닌가? | 기존 메신저에 방을 하나 더 만드는 것은 같은 목록과 알림 흐름 안에 대화를 추가하는 것이다. DoU는 다시 봐야 하는 대화를 별도 플레이스로 분리하는 방식이다. |

### 2차: 기존 메신저에서 중요한 대화 주제만 분리할 사용자

기존 메신저는 계속 쓰되, 그 안에서 흘러가면 안 되는 대화 주제만 따로 관리하고 싶은 사용자입니다.

| 핵심 상황 | 일상 대화와 중요한 대화가 기존 메신저 안에서 함께 오감                     |
| ----- | --------------------------------------------------- |
| 핵심 문제 | 중요한 링크, 일정, 결정사항이 흘러가고 나중에 다시 찾기 어려움                |
| 행동 유도 | 기존 대화를 옮기는 것이 아니라, 앞으로 다시 봐야 할 대화만 DoU에서 새로 이어가게 한다 |


#### 예상 질문

| 질문                             | 대응                                                                          |
| ------------------------------ | --------------------------------------------------------------------------- |
| 기존 메신저랑 DoU를 두 개 쓰는 건 번거롭지 않나? | 모든 대화를 두 앱으로 나누는 것이 아니라, 기존 메신저는 일상 연락용으로 그대로 두고 다시 봐야 하는 일부 대화만 DoU로 분리한다. |

### 3차: DoU를 혼자 먼저 시작할 사용자

아직 초대할 사람은 없지만, DoU를 가볍게 시작해볼 수 있는 진입 사용자가 될 수 있는 사용자입니다.

| 핵심 상황   | 초대할 사람은 없지만, 앱을 먼저 가볍게 써볼 수 있는 시작점이 필요함         |
| ------- | ----------------------------------------------- |
| 핵심 문제   | 초대 기반 서비스는 처음 시작할 이유가 약할 수 있음                   |
| 행동 유도   | 나와의 채팅으로 링크, 메모, 아이디어를 남기며 DoU 사용 흐름을 먼저 익히게 한다 |

#### 예상 질문

| 질문                      | 대응                                                                              |
| ----------------------- | ------------------------------------------------------------------------------- |
| 기존 메신저의 나와의 채팅과 뭐가 다른가? | DoU의 나와의 채팅은 기존 메신저의 나와의 채팅을 대체하기 위한 기능이 아니다. 사람을 초대하기 전 DoU를 먼저 시작해보는 진입 방식이다. |


### 전환 보강 요소: 초대, 삭제, 데이터 관리에 대한 통제감

해당 요소는 별도 타깃으로 분리하기보다, 모든 타깃의 전환을 보강하는 신뢰 요소로 사용한다.

| 역할     | 설치 전 불안을 줄이는 신뢰/통제감 보강 요소              |
| ------ | -------------------------------------- |
| 핵심 상황  | 대화 상대, 대화 공간, 기록 삭제를 직접 관리하고 싶음        |
| 핵심 문제  | 불필요한 연결, 초대, 남아 있는 대화 기록에 부담을 느낌       |
| 행동 유도  | 필요한 사람만 채팅방에 초대하고, 끝난 대화는 삭제해 정리하게 한다  |

## 8. 전략 포지셔닝


DoU는 모든 대화를 옮기기 위한 메신저가 아니다.

DoU는 **새로 시작하는 목적형 대화**와 **기존 메신저 안에서 흘러가면 안 되는 대화 주제**를 플레이스별로 나누어 관리하는 초대 기반 퍼스널 메신저다.

- **Personal**: 개인 중심의 메신저
- **Private**: 대화 보호와 프라이버시
- **Invite-only**: 초대받은 사람만 참여
- **Secure**: 안전한 대화 환경
- **Controlled**: 사용자가 직접 관리하는 관계와 데이터

## 10. 최종 요약

DoU는 **프라이버시와 관계 분리를 중요하게 생각하는 사용자를 위한 퍼스널 메신저**입니다.

일상 메신저가 다양한 관계를 한곳에서 연결하는 도구라면, DoU는 사적인 대화나 소규모 모임처럼 **분리해서 관리하고 싶은 대화**에 적합합니다.
### 핵심 정리

- **관계 분리**: 필요한 사람들과만 대화하는 공간
