
# Few-Shot Prompting Usecase

---

## 개요

Few-Shot Prompting은 LLM에 입력-출력 예시를 제공하여 모델이 패턴을 파악하고 새로운 입력에 동일하게 적용하도록 유도하는 기법이다. 본 문서는 실제 Eureka Flow에서 Few-Shot Prompting을 적용한 유즈케이스를 기록한다.

예시 없이 작업 지시만 제공하면 모델이 형식, 톤, 길이를 스스로 판단한다. 입력-출력 예시를 제공하면 모델이 패턴을 파악하여 일관된 형식의 출력을 생성한다.

## 문제점

작업 지시만으로는 모델이 원하는 형식과 톤을 정확히 파악하지 못한다. 별도의 예시가 없으면 모델이 형식, 길이, 톤을 스스로 판단하여 의도와 다른 결과가 나올 수 있다.

**기본 실행 결과**

```
스탠딩 데스크의 브랜드 아이덴티티나 타겟 고객에 따라
선택하실 수 있도록 네 가지 컨셉으로 나누어
카피를 작성해 보았습니다.

### 1. 건강과 컨디션 강조형
"당신의 허리가 숨 쉬는 높이"
...
### 2. 업무 효율 및 집중력 강조형
...
### 3. 라이프스타일 및 디자인 강조형
...
### 4. 감성 및 동기부여형
...
```

**문제점 정리**

첫째, 요청하지 않은 여러 컨셉으로 분기된다. 하나의 카피를 요청했는데 4가지 컨셉으로 나누어 출력한다.

둘째, 형식이 제각각이다. 메인 카피, 서브 카피, 슬로건처럼 요청하지 않은 구조가 자동으로 생성된다.

셋째, 팁, 활용 방법 등 불필요한 내용이 추가된다. 카피만 요청했는데 활용 방법까지 자동으로 생성된다.

---

## 유즈케이스

### 주제

브랜드 카피 생성

### 유형

형식 일관성 (Format Consistency)

### 목표

예시 없이 작업 지시만 했을 때와 입력-출력 예시를 제공했을 때 출력이 어떻게 달라지는지 확인한다.
동일한 인풋에서 시스템 프롬프트만 다르게 적용하여 Few-Shot Prompting의 효과를 2단계로 비교한다.

---

## 공통 인풋

1단계와 2단계 모두 동일한 유저 인풋을 사용한다.

**User**

```
제품: 스탠딩 데스크
카피: 
```

---

## 2단계 비교

### 1단계 — Zero-Shot (예시 없음)

작업 지시만 제공한 경우다. 예시가 없어 모델이 형식, 톤, 길이를 스스로 판단한다.

**System**

```
당신은 유능한 어시스턴트입니다.
- 브랜드 카피를 작성하세요.
```

**결과**

```
스탠딩 데스크의 브랜드 아이덴티티나 타겟 고객에 따라 선택하실 수 있도록 네 가지 컨셉으로 나누어 카피를 작성해 보았습니다.

---

### 1. 건강과 컨디션 강조형 (Health & Wellness)
**"당신의 허리가 숨 쉬는 높이"**

*   **메인 카피:** 앉아 있는 시간만큼 당신의 몸은 굳어갑니다. 이제 일어서서 몸의 리듬을 깨우세요.
*   **서브 카피:** 10cm의 변화가 만드는 가벼운 허리, 맑은 정신. 당신의 건강한 내일을 위해 책상의 높이를 바꿉니다.
*   **슬로건:** 몸을 세우면, 컨디션이 살아납니다.

### 2. 업무 효율 및 집중력 강조형 (Productivity & Focus)
**"집중력의 높이를 설계하다"**

*   **메인 카피:** 오후 3시, 쏟아지는 졸음과 정체된 아이디어. 책상을 높이는 순간, 새로운 몰입이 시작됩니다.
*   **서브 카피:** 멈춰있던 사고를 깨우는 가장 역동적인 업무 방식. 당신의 성과는 당신의 자세에서 결정됩니다.
*   **슬로건:** 일하는 방식의 진화, [브랜드명] 스탠딩 데스크.

### 3. 라이프스타일 및 디자인 강조형 (Lifestyle & Modern)
**"공간에 리듬을, 일상에 자유를"**

*   **메인 카피:** 고정된 가구에 몸을 맞추지 마세요. 당신의 움직임에 따라 유연하게 반응하는 스마트 워크스테이션.
*   **서브 카피:** 미니멀한 디자인에 담긴 완벽한 기술력. 어떤 공간에서도 당신을 가장 돋보이게 만드는 높이.
*   **슬로건:** 나에게 맞춘 가장 완벽한 각도.

### 4. 감성 및 동기부여형 (Inspirational)
**"나를 세우는 시간"**

*   **메인 카피:** 단순히 서서 일하는 것이 아닙니다. 나 자신을 더 소중히 여기는 태도를 갖추는 것입니다.
*   **서브 카피:** 더 높은 곳을 바라보는 당신을 위해, [브랜드명]이 당신의 시선을 높여드립니다.
*   **슬로건:** 당신이 일어서는 순간, 세상이 달라 보입니다.

---

**💡 팁:**
*   **상세 페이지 상단**에는 '집중력'이나 '건강'을 강조한 짧고 강렬한 문구를 배치하세요.
*   **SNS 광고**에는 "오후 3시, 아직도 앉아 계신가요?"와 같은 공감형 질문으로 시작하는 것이 효과적입니다.
*   **브랜드 이름**을 [브랜드명] 자리에 넣어 활용해 보세요!
...
```

요청하지 않은 4가지 컨셉으로 분기되었고 메인 카피, 서브 카피, 슬로건처럼 불필요한 구조가 자동으로 생성되었다. 카피만 원했는데 활용 팁까지 포함되었다.

---

### 2단계 — Few-Shot 적용

입력-출력 예시를 제공한 경우다. 모델이 예시에서 형식, 톤, 길이 패턴을 파악하여 동일하게 적용한다.

**System**

```
당신은 유능한 어시스턴트입니다.

아래 예시의 톤과 형식으로 제품 소개 문구를 작성하시오.

###
제품: 보온 텀블러
카피: "12시간, 당신의 커피는
       처음 그 온도 그대로입니다.
       바쁜 하루 속에서도 한 모금의 여유를."
###
제품: 무선 이어폰
카피: "선 없이, 방해 없이.
       온전히 음악에만 집중하는 시간.
       8시간 연속 재생, 그리고
       10분 충전으로 2시간 더."
###
제품: 스탠딩 데스크
카피:
```

**결과**

```
"앉아 있는 시간에서 벗어나
당신의 컨디션을 깨우는 높이.
부드러운 움직임으로 완성하는
가장 건강한 몰입의 순간."
```

예시의 톤과 형식을 그대로 따라 짧고 감성적인 카피 하나만 출력되었다. 불필요한 컨셉 분기, 구조 설명, 팁이 사라졌다.

---

## 프롬프트 구성요소별 역할 분석

| 구성요소   | 내용      | 역할                |
| ------ | ------- | ----------------- |
| 구분자    | ###     | 예시 간 경계를 명확히 구분   |
| 입력 예시  | 제품명 2개  | 어떤 형태의 입력인지 패턴 전달 |
| 출력 예시  | 카피 2개   | 원하는 톤, 길이, 형식 전달  |
| 새로운 입력 | 스탠딩 데스크 | 모델이 완성해야 할 부분     |

---

## 적용 효과

|항목|1단계 (Zero-Shot)|2단계 (Few-Shot)|
|---|---|---|
|출력 형식|모델이 임의 결정|예시와 동일한 형식|
|컨셉 수|4가지로 분기|하나로 통일|
|톤|제각각|예시와 일관된 톤|
|불필요한 내용|팁, 활용법 포함|카피만 출력|
|길이|과도하게 김|예시와 유사한 길이|

---

## 핵심 결과

예시 없이 작업 지시만 했을 때 모델은 형식, 톤, 길이를 스스로 판단하여 요청하지 않은 구조와 내용을 자동으로 생성했다.

입력-출력 예시를 2개 제공하자 결과가 달라졌다. 모델이 예시에서 패턴을 파악하여 동일한 형식의 카피 하나만 출력했다. 텍스트로 설명하기 어려운 톤과 문장 리듬까지 예시를 통해 전달되었다.

> 예시 없을 때: 모델이 형식을 스스로 판단 → 의도와 다른 결과
> 
> 예시 2개 제공: 패턴 파악 → 예시와 일관된 형식으로 출력

## Few-Shot Prompting 원칙

- **구분자를 명확히** — `###` 같은 구분자로 예시 간 경계를 명확히 해야 모델이 패턴을 정확히 파악한다
- **형식 일관성** — 모든 예시가 동일한 구조를 따라야 한다. 입력/출력 형식이 예시마다 다르면 모델이 혼란을 겪는다
- **수보다 질** — 예시가 많다고 좋은 게 아니다. 원하는 패턴을 명확히 보여주는 2~3개가 더 효과적이다
- **마지막 입력은 비워두기** — 모델이 완성해야 할 부분의 출력은 비워야 한다
